開發者說明（維護/擴充指南）

本頁面是給「之後要接手修改的人」看的說明，目的在於讓你不用讀完整份程式碼，也能快速知道：目前功能、資料結構、流程與擴充方法。

1. 檔案型態與執行方式

  • 本遊戲是單檔 HTML，含 CSS/JS/題庫資料，可離線使用。
  • 不依賴外部 CDN 或套件；直接用瀏覽器開啟即可。
  • iOS/Safari 注意：JS 字串不可出現「未轉義換行」，若要換行請使用 \n。

2. 主要 UI 區塊

  • 左側控制面板：科目、題組、模式、字體大小、登入/遠端紀錄操作。
  • 中央遊戲區：題目、選項、作答回饋、敵我血量與動畫。
  • 結算畫面：顯示答對/答錯、命中率、總分 100，並提供獎勵關卡。
  • 彈窗：考前重點整理、遠端成績紀錄。

3. 題庫資料結構（新增題目最重要）

題庫是 JS 陣列，每題是一個物件。新增題目時請遵守：

{
  id: "唯一ID字串",             // 必填：錯題本會用 id 回查題目
  subject: "社會",              // 必填：科目（社會/國語/自然/英文...）
  topic: "單元三",              // 必填：題組分類（可自訂）
  type: "單選|多選|是非",        // 必填
  q: "題幹文字",                // 必填
  options: ["A ...","B ..."],   // 必填：建議已含字母前綴
  answer: 0 或 [0,2],           // 必填：單選/是非=number，多選=array
  hint: "提示文字(可選)",
  explain: "解說文字(可選)"      // 建議：會在作答後/結算顯示
}
  • 多選題 answer 請用索引陣列，例如 [0,2,3]。
  • 是非題固定兩個選項：["A 是（○）","B 否（×）"]。

4. 題庫來源與合併

  • QUESTION_BANK：原始題庫（單元三/四、試卷題庫等）。
  • GEN_BANK：自動生成示範題庫（100 題）。
  • ALL_BANK = QUESTION_BANK.concat(GEN_BANK)：合併後總題庫。

5. 篩選規則（科目 + 題組）

  • 科目下拉 subjectSel：用題目物件的 subject 欄位過濾。
  • 題組下拉 unitSel：用題目物件的 topic 欄位過濾。
  • 社會題組（全部）會依題幹去除重複題目，避免同題重複出現。
  • 核心函式：filterBank()，會回傳本回合可抽題的清單。

6. 遊戲流程（Lifecycle）

  • startFromList(list)：開始一回合；建立題單、重置統計、進入第 1 題。
  • renderQuestion()：渲染題目與選項，初始化計時/按鈕狀態。
  • revealAnswer(...)：判斷正誤→更新血量/統計→寫入錯題本→顯示解析。
  • next()：進入下一題；結束時呼叫結算。
  • finish()：結算並顯示成績/獎勵關卡。

練習模式允許「顯示答案」且不扣分；測驗模式會禁用顯示答案。開始後會切換全版面。

7. 計分（總分 100）

  • 每題配分：100 / 本回合題數（自動計算）。
  • 總分：(答對 / 本回合題數) * 100（四捨五入到 1 位小數）。
  • 顯示位置：左側 KPI 與結算畫面。

8. 錯題本（localStorage）

  • 答錯時會把該題 id 記錄到 localStorage["quizWrongBookV1_social"] / localStorage["quizWrongBookV1_natural"]。
  • 下次可選「錯題本」或「錯題題組」只練錯題。
  • 清空錯題本：可在程式中提供按鈕，或手動清除瀏覽器網站資料。

9. 獎勵關卡（Bonus Games）

  1. bonus/tower：疊塔遊戲。
  2. bonus/2048：2048。
  3. bonus/memory：記憶翻牌。
  4. 以 iframe 延遲載入，展開時嘗試進入全螢幕。
  5. 達標後僅能遊玩 1 次，限時 5 分鐘，時間到自動關閉。
  6. 授權資訊在各資料夾 NOTICE.md / LICENSE。

10. 考前重點整理

  • 按「輸出考前重點」可生成各科重點 Markdown。
  • 邏輯：優先用 explain / hint，不足時補題幹＋答案。

11. 遠端成績紀錄（Google Apps Script）

  • 登入使用暱稱＋PIN；結算時自動送出成績。
  • 設定：REMOTE_ENDPOINT、REMOTE_KEY。
  • 本機記住登入：quizRemoteAuthV1。
  • 「查看歷史」會從遠端讀取最近成績。

12. 密碼結束與版本

  • 「密碼結束」使用 BONUS_PASS，可直接解鎖獎勵並結束本局。
  • 版本徽章來自 document.lastModified。

13. 如何加入新科目（國語/自然/英文）

  1. 把新科目的題目轉成上述題目物件格式。
  2. 每題加上 subject: "國語"（或自然/英文）。
  3. 把左側「科目」選單的 disabled 拿掉，或新增更多科目選項。
  4. 不需要改核心邏輯：filterBank() 會自動依 subject/topic 篩選。

提示：若你要把題庫做成「可熱插拔」的 JSON 檔或多檔載入，也可以延伸成 fetch() 載入。但為了 iOS 離線相容，目前採用單檔最穩定。
